# Комплект по персональным данным

Дата подготовки: 03.08.2026.

Этот каталог помогает ИП Пушкареву Кириллу Александровичу подготовить уведомление Роскомнадзора и внутренние документы по обработке персональных данных. Публичная политика и согласие находятся в исходном коде сайта `app/src/data.js`.

## Что находится в комплекте

- `OWNER-QUESTIONNAIRE.md` — сведения, которые владелец должен подтвердить до подачи.
- `RKN-NOTIFICATION-DRAFT.md` — черновик полей уведомления по форме приказа Роскомнадзора N 180.
- `INTERNAL-PD-REGULATION.md` — базовый внутренний порядок работы с персональными данными.
- `CONSENT-FOR-DISTRIBUTION-TEMPLATE.md` — отдельное согласие для будущей публикации имени, фотографии или отзыва клиента.
- `DATA-DELETION-ACT-TEMPLATE.md` — форма подтверждения удаления или уничтожения данных.
- `INCIDENT-RESPONSE.md` — порядок действий при утечке или неправомерном доступе.

## Что уже исправлено на сайте

1. Согласие на обработку заявки отделено от ознакомления с политикой.
2. Чекбокс заранее не отмечен и обязателен перед открытием Telegram.
3. В отправляемый пользователем текст добавляются время, редакция и ссылка на согласие.
4. Именной отзыв обезличен.
5. Политика содержит категории субъектов, способы обработки, сроки удаления, внешние сервисы и правила публикации отзывов.
6. Аналитика загружается только после отдельного добровольного разрешения.

## Что нельзя закончить программным кодом

До подачи владелец должен заполнить обязательные поля анкеты: полный адрес оператора, email, фактическую дату начала обработки, место российской базы данных, перечень подрядчиков и сведения о трансграничной передаче. Заполненную копию с домашним или иным непубличным адресом нельзя коммитить в открытый GitHub-репозиторий.

Уведомление подается владельцем или уполномоченным лицом через официальный портал Роскомнадзора: https://pd.rkn.gov.ru/operators-registry/notification/form/

Для заполненных копий используйте каталог `private` или суффикс `-filled`, `-signed` либо `-submitted`: такие файлы исключены через `.gitignore`. Перед отправкой проверьте `git status`, чтобы адрес регистрации, email, сведения о базах и подпись не попали в публичный репозиторий.

## Нормативные ориентиры

- статья 9 Федерального закона N 152-ФЗ — согласие и обязанность подтвердить его получение;
- статья 12 Федерального закона N 152-ФЗ — трансграничная передача;
- статья 18 часть 5 Федерального закона N 152-ФЗ — первичная запись и хранение в РФ;
- статья 21 Федерального закона N 152-ФЗ — прекращение обработки и уничтожение;
- статья 22 Федерального закона N 152-ФЗ — уведомление Роскомнадзора;
- приказ Роскомнадзора от 28.10.2022 N 180 — форма уведомления;
- приказ Роскомнадзора от 24.02.2021 N 18 — отдельное согласие на распространение.

Если используются иностранные сервисы и имеет место трансграничная передача, до ее начала требуется отдельное уведомление по статье 12 Федерального закона N 152-ФЗ. Этот вопрос нельзя закрыть одной политикой на сайте.
