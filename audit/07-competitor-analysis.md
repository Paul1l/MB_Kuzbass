## Что сравнивать (шаблон для проверки по выдаче)

Для каждого P1-кластера снять топ-10 Яндекса (Барнаул, lr=197; для негеозависимых — Россия, lr=225) и топ-10 Google. Для каждого URL заполнить:

| Поле | Что фиксировать |
|---|---|
| Тип страницы | Категория, карточка, бренд, модель, статья, агрегатор, справочник, карты |
| Title и H1 | Формулировки («разборка», «б/у», «контрактные»), город, бренд |
| Контент | Объём, наличие таблиц совместимости, описаний доноров, FAQ |
| Категории и фильтры | Марка → модель → кузов → категория; фильтры по году и коду |
| Ассортимент | Количество позиций по кластеру, цены, статусы |
| Внутренние ссылки | Крошки, связанные товары, перелинковка моделей |
| Микроразметка | Product, Offer, BreadcrumbList, LocalBusiness |
| UX | Поиск по VIN или номеру, быстрый звонок, мессенджеры, мобильная версия |
| Доверие | Гарантия (сроки), возврат, отзывы, реквизиты, фото склада |
| Локальные сигналы | Адрес в городе, карточки на картах, городской поддомен или страница |
| Доставка | Компании, сроки, калькулятор |
| Контакты | Телефон в шапке, режим работы, мессенджеры |
| Коммерческие факторы | Цены, наличие, способы оплаты, онлайн-заказ |
| Скорость | PageSpeed Insights (мобильный) |

## Гипотезы: почему ранжируются конкуренты (проверить)

| Тип | Вероятные причины | Что взять MB Kuzbass (не копируя) |
|---|---|---|
| Агрегаторы (Drom, маркетплейсы) | Огромный ассортимент по каждой модели и детали, цены, свежие объявления, сильный домен, поведенческие сигналы | Показывать собственный ассортимент на сайте с ценой или «по запросу» и статусом; ссылаться на профиль Drom и обратно |
| Федеральные сети с городскими поддоменами (Евроавто) | Местный адрес и телефон на поддомене, гарантия, доставка, цены, большой склад | Явный местный адрес и карточки в Барнауле; реальные условия гарантии и доставки |
| Справочники разборок (Ferio, Справкер, auto2you, Carpis, naRule) | Собирают много компаний под запрос «разборка {марка} {город}» | Получить корректные карточки компании в этих справочниках — это и упоминания (NAP), и переходы ([16-backlink-authority-plan.md](16-backlink-authority-plan.md)) |
| Монобрендовые разборки | Страницы по моделям и кузовам, глубокая специализация | Модельные страницы там, где есть реальные доноры и спрос |
| Специалисты по распилам | Отдельная страница под каждую марку, понятная схема, сроки, кейсы | Страница `/postavki-dlya-avtorazborov/` с реальной схемой работы, кейсами и условиями от владельца |

## Возможности, которые уже видны

1. **Узкая специализация** (только Mercedes-Benz и BMW, только японские доноры) — можно глубже раскрыть конкретные узлы и доноров, чем это делают агрегаторы.
2. **Товарные страницы с реальными фото и номерами** — длинный хвост «код + купить», где у агрегаторов часто чужие или устаревшие объявления.
3. **Карты** (Яндекс Бизнес, 2ГИС) — по локальным запросам часто показываются блоки карт; рейтинг 4.8 в 2ГИС уже есть.
4. **Справочники разборок** — бесплатные и легитимные упоминания компании в Барнауле.
5. **B2B-направление** — у конкурентов во Владивостоке нет склада в Сибири; если у MB Kuzbass реальная логистика до Сибири, это аргумент для разборок Сибири (проверить с владельцем).
