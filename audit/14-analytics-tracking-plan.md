## Важное ограничение: opt-in

Метрика видит только тех, кто нажал «Разрешить аналитику». Какая это доля — неизвестно, и без счётчика её не измерить. Последствия:
- абсолютные числа визитов и целей в Метрике занижены;
- для поисковых показов и кликов основной источник — **Вебмастер и Search Console** (они не зависят от cookie на сайте);
- решение, оставлять ли opt-in, — за владельцем и юристом; аналитик не меняет порядок согласия.

### 3. Код источника в сообщении (связь с продажей)

Каждый CTA формирует текст сообщения с коротким кодом, например:

```text
Здравствуйте! Интересует: Двигатель Mercedes-Benz M272 (ID 0012).
Код: S-ENG-0012
```

- `S` — сайт; дальше — тип страницы и ID товара.
- WhatsApp: `https://wa.me/79235362777?text=…` (предзаполнение работает).
- Telegram: `https://t.me/MB_Kuzbass?text=…` — проверить, что клиенты Telegram подставляют текст; если нет — копирование в том же клике.
- Менеджер вносит код в журнал лидов: дата, канал, код, деталь, итог, сумма.

### 4. Журнал лидов и продаж

Простая таблица (без лишних персональных данных; хранение — с учётом 152-ФЗ и места хранения в РФ):

| Дата | Канал | Код источника | Деталь / ID | Город покупателя | Итог (продано / нет / в работе) | Сумма | Причина отказа |
|---|---|---|---|---|---|---|---|

Раз в месяц — сверка: органические посадочные страницы (Вебмастер, Метрика) ↔ коды в журнале ↔ продажи.

### 5. Вебмастер и Search Console

- Вебмастер: регион сайта, главное зеркало, sitemap, «Страницы в поиске», «Проверка ответа сервера», мониторинг важных страниц, настройка обработки JavaScript, группы запросов (кластеры из CSV).
- Search Console: подтверждение уже есть (DNS); выдать доступ аналитику, отправить sitemap, проверить отчёт об индексации.

### 6. Отладка и тесты

- `?_ym_debug=1` для проверки целей.
- E2E-тест: до согласия нет запросов к `mc.yandex.ru`; после согласия цели уходят с параметрами.
- Ежемесячно: сверка «клики в Метрике» ↔ «записи в журнале».

## Воронка

```text
Органический вход (Вебмастер: показы → клики по кластерам)
  → Вовлечение (Метрика: глубина, время, прокрутка; доля отказов)
  → Категория / бренд / модель (catalog_category_view)
  → Товар (product_view с параметрами)
  → Контакт (lead_any: звонок, WhatsApp, Telegram, VIN, форма)
  → Переписка начата (журнал: код источника)
  → Продажа (журнал: статус, сумма)
```
