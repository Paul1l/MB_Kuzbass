# 1. Executive SEO Summary

**Проект:** mb-kuzbass.ru — ИП Пушкарев К. А., б/у оригинальные (контрактные) запчасти Mercedes-Benz и BMW с японских доноров, авто с японских аукционов, машинокомплекты для авторазборов. Склад и выдача — Барнаул (Кузбасс — только название бренда); доставка по России. Домен — Webnames, хостинг и DNS — Спринтхост.

**Цель:** не трафик, а цепочка «поисковый спрос → релевантная страница → квалифицированный посетитель → поиск детали → звонок или сообщение → продажа».

## Вывод в одном абзаце

Живой сайт опережает репозиторий: на production уже есть 7 статичных посадочных страниц (бренды, двигатели и АКПП, кузов и оптика, авто из Японии, поставки для разборов, «контрактные запчасти») и переписанные Title и H1 главной. Но этих изменений нет в Git, и **любая выкладка из репозитория их откатит** — это первый риск. Главная по-прежнему приложение на JavaScript с пустым HTML; она не ссылается ни на одну посадочную, а пункт «Каталог» на посадочных открывает главную наверху. Главная и `/kontraktnye-zapchasti-barnaul/` конкурируют за один запрос. Все заявки идут в публичную Telegram-группу. И главное: у продавца **8 123 объявления на Drom** с ценами и OEM-номерами, а на сайте — 30 карточек без цен и без собственных адресов. Самый большой рычаг роста — перенести реальное наличие на сайт страницами товаров.

## Что подтверждено, а что нет

| Подтверждено (код, сервер, DNS, Drom) | Не подтверждено (DATA NOT VERIFIED) |
|---|---|
| Главная — SPA с пустым HTML; 7 статичных посадочных на production, которых нет в Git | Частоты Wordstat, позиции, трафик |
| Редиректы `http`→`https` и `www`→без `www` работают одним переходом; без слэша — 2 перехода через `http` | Данные Вебмастера, Search Console, Метрики |
| GitHub Pages публикует репозиторий, включая внутренние документы | Карточка в Яндекс Бизнесе, регион сайта в Вебмастере |
| `gzip` включён; Lighthouse production (mobile): главная 93, посадочная 90 | Полевые Core Web Vitals, TTFB из России |
| Заявки во всех CTA — в группу `t.me/mbc_kuzbass` | Конверсия в заявки и продажи |
| На Drom 8 123 объявления, рейтинг продавца 100%, почти 10 лет на площадке, два телефона | Полный состав ассортимента (выборка — 250 объявлений) |
| Хостинг и DNS — Спринтхост, Cloudflare нет; Search Console подтверждён через DNS; почта на домене настроена | Данные 2ГИС (площадка отвечает 403) |
| География: только Барнаул; заявки — `@MB_Kuzbass` (ответы владельца) | Города регулярной доставки |

> Оценка Lighthouse SEO = 100 не означает, что SEO в порядке: Lighthouse проверяет базовые теги одной страницы.

## Ожидаемый эффект (качественно, без выдуманных цифр)

- **0–30 дней:** production и Git синхронизированы, GitHub Pages закрыт, заявки идут в личный канал, посадочные связаны с сайтом, каталог открывается, аналитика и Wordstat собраны. Эффект — больше заявок с текущего трафика и корректные данные.
- **31–60 дней:** импорт наличия и первые сотни страниц товаров с реальными данными; разведённые главная и «контрактные запчасти»; страница дисков и подвески; коммерческие страницы. Эффект — показы по номерам деталей и «деталь + кузов» (замер — Вебмастер).
- **61–90 дней:** пререндер главной, страницы моделей (W211, W203, X3 E83 и др.) при подтверждённом спросе, отзывы, ссылки с профилей площадок. Эффект — рост квалифицированных кликов и обращений по длинному хвосту.

Прогноз трафика и заявок в цифрах не даётся: без Wordstat, Вебмастера и Метрики он был бы выдумкой.

## KPI

Основные: квалифицированные обращения из органики (звонки, сообщения, заявки с кодом источника), продажи из органики, конверсия органики. Промежуточные: показы и клики по коммерческим кластерам в Вебмастере, доля небрендовых запросов, число проиндексированных страниц товаров, CTR сниппетов, позиции по кластерам в Барнауле и по России для негеозависимых запросов (номера деталей, коды агрегатов).

## Чего мы сознательно не делаем

- Не меняем адреса работающих посадочных без анализа редиректов.
- Не создаём гео-страницы для городов без присутствия (точек вне Барнаула нет).
- Не генерируем страницы «модель × деталь» без спроса и наличия; не публикуем товары без реальных данных.
- Не копируем описания Drom как есть — у страниц товаров на сайте должны быть свои данные и фото.
- Не размечаем рейтинг 2ГИС как собственный.
- Не придумываем цены, гарантию, сроки, отзывы и наличие — только со слов владельца или из его объявлений.
- Не закупаем ссылки.
