# 11. Контент-план (фаза 12)

Принцип: текст помогает человеку найти и купить конкретную деталь. Никаких «SEO-текстов» ради объёма, никаких выдуманных фактов. Title, Description и H1 для страниц — в [09-on-page-plan.md](09-on-page-plan.md).

## Коммерческие страницы

### Главная `/`

| Поле | Содержание |
|---|---|
| Основной интент | Найти, где купить б/у запчасти Mercedes-Benz и BMW в Барнауле или с доставкой |
| Кластеры | NAV-BRAND, BR-BOTH-LOCAL, USP, VIN |
| Структура | 1) H1 + одно предложение о предложении + CTA (телефон, WhatsApp, Telegram, «Подобрать по VIN») 2) Категории (6 карточек со ссылками) 3) Бренды (Mercedes-Benz, BMW) с моделями в наличии 4) Новые поступления (последние товары) 5) Как мы работаем (VIN → фото и видео → согласование → отправка) 6) Доставка и оплата (кратко, ссылка) 7) Отзывы и рейтинг 8) Направления: авто из Японии, поставки для разборов (ссылки) 9) Контакты и карта |
| H2 | Категории запчастей · Mercedes-Benz и BMW в наличии · Новые поступления · Как подбираем деталь · Доставка по России · Отзывы клиентов · Авто из Японии и поставки для разборов · Контакты |
| FAQ | Только реальные вопросы клиентов из переписки (попросить у владельца 5–7 частых вопросов) |
| Ссылки | Все категории, бренды, 6–12 последних товаров, доставка, контакты |
| CTA | «Позвонить», «Написать в WhatsApp», «Написать в Telegram», «Подобрать по VIN» |
| Доверие | Реальные фото склада и доноров, рейтинг 2ГИС с датой, реквизиты ИП, условия (если есть гарантия — её суть) |

### Категория (пример — `/dvigateli-akpp-mercedes-bmw-barnaul/`, есть на production)

| Поле | Содержание |
|---|---|
| Интент | Купить контрактный двигатель для Mercedes-Benz или BMW |
| Кластеры | CAT-ENG, ENG-MODEL |
| Структура | H1 → 2–3 предложения: откуда агрегаты, что проверяем → список товаров (фото, код, донор, состояние, цена или «по запросу», статус, CTA) → «Как проверяем двигатель перед продажей» (реальный процесс) → «Что прислать для подбора» (VIN, код двигателя, фото шильдика) → доставка и упаковка агрегатов → гарантия (если есть) |
| H2 | Двигатели в наличии · Как проверяем перед продажей · Как подобрать двигатель по VIN · Доставка двигателей |
| FAQ | «Что входит в комплект (навесное)?», «Есть ли пробег донора?», «Как отправляете?» — по ответам владельца |
| Ссылки | Товары; соседние категории (АКПП); бренды; статьи по кодам (если созданы) |
| CTA | На карточке: «Спросить про {код}» с ID товара |
| Доверие | Фото маркировок, видео запуска (если владелец снимает), описание проверки |

Остальные категории по той же схеме, со своими акцентами:
- **АКПП** — код коробки по маркировке, совместимость по VIN, как перевозить.
- **Оптика** — состояние стёкол и креплений, сторона, тип (ксенон или галоген), особенности фар с автомобилей для левостороннего движения (только проверенные факты).
- **Кузов** — состояние по фото, порядок перевозки и документов (без обещаний регистрации).
- **Диски, подвеска, тормоза** — диаметр, вылет, разболтовка, износ, комплектность.
- **Салон** — цвет, материал, электрика и подогрев, комплект.

### Страница товара (шаблон)

| Блок | Содержание |
|---|---|
| H1 | {Деталь} {Бренд} {кузов} {код} |
| Галерея | Все реальные ракурсы, маркировки, дефекты |
| Ключевые данные | Статус, цена или «по запросу», код и OEM, донор, год, сторона, состояние, пробег (если подтверждён), город |
| Совместимость | Только подтверждённая продавцом; иначе «Проверим по VIN» |
| CTA | «Позвонить», «WhatsApp: Интересует {ID} {название}», «Telegram» |
| Доставка | Кратко + ссылка |
| Похожие | Та же категория и модель; те же коды |
| Разметка | `Product` (+ `Offer` при видимой цене), `BreadcrumbList` |

### Авто из Японии `/avtomobili-iz-yaponii-barnaul/` (есть на production)

Интент: заказать автомобиль Mercedes-Benz или BMW с японского аукциона. Структура: как работаем (этапы и сроки — от владельца) → что входит в стоимость (только реальная схема, без выдуманных цифр) → примеры привезённых авто (реальные фото с разрешения) → документы и растаможка (проверенная информация) → CTA. Доверие: реальные кейсы, договор (если есть). Учесть: направление высококонкурентное, ожидания по трафику умеренные.

### Поставки для авторазборов `/postavki-dlya-avtorazborov-barnaul/` (есть на production)

Интент: B2B-закупка машинокомплектов и распилов. Структура: форматы (машинокомплект, распил, контейнер) → марки и модели → схема работы и сроки → география поставок → условия оплаты и минимальный объём (от владельца) → кейсы → форма или контакт для оптовиков. CTA: «Обсудить поставку». Доверие: фото контейнеров и отгрузок, реквизиты.

### Доставка и оплата, гарантия, контакты, о компании

Только факты владельца: транспортные компании, сроки до крупных городов Сибири, упаковка агрегатов, кто оплачивает доставку, способы оплаты, возврат, гарантия (если есть). «О компании» — подтверждённый факт «MB Kuzbass — название бренда, склад и выдача в Барнауле»; история названия, склад, люди, сколько лет работают — со слов владельца.

### Страница модели (условно, шаблон)

H1 «Запчасти Mercedes-Benz W211 б/у» → годы и рестайлинг → какие доноры приходят → товары этой модели по категориям → совместимость двигателей и коробок (проверенные данные) → подбор по VIN. Создаётся только по правилам из [08-site-architecture.md](08-site-architecture.md#когда-создаётся-страница-модели-или-кузова).

## Процесс

1. Владелец заполняет анкету фактов ([20-owner-questions-and-access.md](20-owner-questions-and-access.md)).
2. Контент-стратег готовит черновики по шаблонам.
3. Владелец проверяет факты; при необходимости — юрист (условия, гарантия, документы на кузова).
4. Публикация вместе со страницей; проверка без JS.
5. Обновление: товары — при каждом изменении наличия; категории и бренды — ежемесячно; статьи — раз в полгода.
