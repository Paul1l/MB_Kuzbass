# 3. Исследование Yandex Wordstat

## Статус

**Реальные данные Wordstat не собраны. Все частоты: DATA NOT VERIFIED.**

Причина: сетевая политика окружения аудита блокирует `wordstat.yandex.ru` и `yandex.ru` (ответ прокси 403), а Wordstat требует входа через Яндекс ID. Встроенный браузер к облачной сессии не подключён. Ни одна цифра частотности в этом аудите не приводится и не оценивается «на глаз».

Что сделано вместо этого:
- построен **список-кандидат** из 239 запросов на основе реального ассортимента (коды кузовов, двигателей, АКПП из каталога), направлений бизнеса и географии ([04-semantic-core.csv](04-semantic-core.csv));
- подготовлена методика, по которой сбор займёт 1–2 рабочих дня у человека с доступом;
- определены правила, по которым после сбора принимаются решения о страницах.

## Как получить данные (любой вариант)

1. Владелец или SEO-специалист входит в `wordstat.yandex.ru` под своим Яндекс ID и выгружает данные по методике ниже.
2. Сессия Claude на компьютере владельца (Claude Desktop или `claude remote-control`) — встроенный браузер с уже выполненным входом в Яндекс.
3. Открыть в настройках облачного окружения доступ к `wordstat.yandex.ru` и `yandex.ru` (вход в аккаунт всё равно понадобится).
4. Сервисы с доступом к частотам Wordstat (Key Collector, Rush Analytics, Topvisor и аналоги) — платно, по выбору владельца.

## Операторы Wordstat

| Запись | Что показывает | Для чего |
|---|---|---|
| `разборка мерседес` | Все запросы, содержащие эти слова в любой форме и с любыми дополнительными словами (широкое соответствие) | Объём «зонтика» и список хвостов |
| `"разборка мерседес"` | Только запросы ровно из этих слов, в любых формах и порядке | Частота самой фразы без хвостов |
| `"!разборка !мерседес"` | Только эти слова в этих формах | Точная частота конкретной формулировки |
| `[мерседес разборка]` | Фиксированный порядок слов | Сравнение порядков слов |
| `-бесплатно` | Исключение слова | Очистка |
| `+на` | Учесть предлог или служебное слово | «запчасти +на мерседес» |
| `(w211\|w212)` | Группировка, «или» | Сравнение близких моделей одним запросом |

Правило отчёта: для каждого ключевого запроса фиксировать три числа — широкое, «фразовое», «точное». Разница между широким и фразовым показывает объём хвоста.

## Порядок работ

1. **Маркеры.** Взять все строки [04-semantic-core.csv](04-semantic-core.csv) с типом «маркер» (короткие запросы кластеров): бренды, категории, коды кузовов, двигателей, АКПП, направления бизнеса.
2. **Широкий сбор.** По каждому маркеру выгрузить все запросы (левая колонка) и похожие запросы, регион «Россия». Для локальных маркеров повторить для Барнаула.
3. **Очистка минус-словами.** Стартовый список ниже; дополнять по результатам.
4. **Точные частоты.** Для оставшихся запросов снять «фразовую» и «точную» частоты.
5. **Регионы.** Для маркеров открыть распределение по регионам: абсолютная доля и региональная популярность (индекс выше 100% означает интерес выше среднего). Сравнить Барнаул, Алтайский край, Кемерово, Новокузнецк, Кемеровскую область, Новосибирск.
6. **Сезонность.** Динамика за 24 месяца для кластеров «диски и колёса», «двигатели», «АКПП», «оптика», «авто из Японии».
7. **Устройства.** Доля мобильных — влияет на приоритет мобильного CRO.
8. **Интент и геозависимость по выдаче.** Для топ-запросов каждого кластера посмотреть выдачу Яндекса: какие типы страниц в топ-10 (категория, карточка, агрегатор, статья); отличается ли выдача в Барнауле и Москве (если да — запрос геозависимый).
9. **Кластеризация по выдаче.** Запросы объединяются в кластер, если в топ-10 совпадает не менее 3–4 URL. Кластер получает одну целевую страницу.
10. **Заполнение CSV.** Заменить `DATA NOT VERIFIED` реальными числами, указать дату снятия и регион, проставить приоритет по правилам ниже.

### Стартовый список минус-слов

| Группа | Слова | Почему |
|---|---|---|
| Бесплатное и самостоятельное | бесплатно, даром, своими руками, самому | Нет коммерческого интента |
| Информация без покупки | схема, фото, видео, обзор, тест, характеристики (проверять: иногда коммерческие), реферат | Информационные; часть может пригодиться для статей — помечать, а не удалять |
| Услуги, которых может не быть | ремонт, замена, диагностика, прошивка, чип-тюнинг | Бизнес продаёт детали, а не ремонт; уточнить ОКВЭД 45.20.1 (ремонт указан как дополнительный вид деятельности) |
| Новые и неоригинальные запчасти | новый, новая, китай, аналог, неоригинал | Ассортимент — б/у оригинал |
| Другие марки и игрушки | ваз, лада, тойота (если не указан Mercedes или BMW), модель 1:18, lego, игрушка | Нерелевантно |
| Площадки | авито, дром, auto.ru | Навигационные запросы к площадкам (учесть отдельно: показывают, где ищут) |
| Работа | вакансии, работа, зарплата | Нерелевантно |

## Как классифицировать после сбора

Классы частотности **не по фиксированным порогам**, а относительно собранного набора: после сбора отсортировать запросы по «фразовой» частоте и разбить на группы.

| Класс | Определение (относительное) |
|---|---|
| Высокочастотные | Верхние ≈ 5% набора по фразовой частоте |
| Среднечастотные | Следующие ≈ 15% |
| Низкочастотные | Следующие ≈ 40% |
| Длинный хвост | Оставшиеся ≈ 40% (обычно 4+ слов, коды, номера) |

Помимо частоты каждому запросу ставятся оценки 0–3:

| Оценка | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Релевантность бизнесу | Не наш товар | Смежный | Наш, но не в наличии | Наш и в наличии |
| Коммерческий интент | Информационный без покупки | Информационный с переходом к покупке | Коммерческий (выбор) | Транзакционный (купить) |
| Подходит под посадочную | Нет страницы и не будет | Нужна статья | Есть категория или бренд | Есть товар или точная страница |
| Конкуренция в выдаче | Только федеральные агрегаторы | Агрегаторы и крупные магазины | Смешанная | Есть слабые локальные сайты |
| Вероятность конверсии | Низкая | Ниже средней | Выше средней | Высокая (код агрегата, модель + деталь, город) |

**Приоритет запроса** = (релевантность + интент + посадочная + конкуренция + конверсия), затем сортировка внутри класса частотности. Итог в CSV: P1 / P2 / P3.

## Гео-исследование: правила решения

Сравнить спрос (широкий и «фразовый») по маркерам в разных регионах:

|---|---|---|---|---|---|---|
| разборка мерседес | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED |
| разборка бмв | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED |
| б/у запчасти мерседес | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED |
| контрактный двигатель мерседес | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED |
| авто из японии под заказ | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED | DATA NOT VERIFIED |

> Владелец подтвердил: компания находится только в Барнауле, «Кузбасс» — название бренда. Для Кемерово, Новокузнецка и Кемеровской области условие 1 не выполнено, поэтому сравнение по ним нужно только для оценки спроса на доставку, а не для отдельных страниц. Алтайский край — регион Барнаула: его запросы обслуживают те же страницы, что и барнаульские.

Отдельная гео-страница создаётся **только если выполнены все четыре условия**:
1. компания реально обслуживает этот город (самовывоз, пункт, регулярная доставка с известными сроками и стоимостью);
2. подтверждён спрос по Wordstat для этого города;
3. страница содержит уникальную полезную информацию (сроки и способы доставки в этот город, примеры отправок, особенности получения), а не замену названия города;
4. есть коммерческий смысл (спрос × конверсия × маржа оправдывают поддержку страницы).

Если условия не выполнены — город упоминается на странице «Доставка и оплата», а не получает отдельную страницу.
