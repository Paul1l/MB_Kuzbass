## 3. Новые проблемы на production

### H-16. Главная и `/kontraktnye-zapchasti-barnaul/` конкурируют за один запрос

| Поле | Значение |
|---|---|
| Критичность | High |
| Область | On-page SEO, каннибализация |
| Описание | H1 главной и посадочной одинаковые: «Контрактные запчасти Mercedes-Benz и BMW в Барнауле»; Title почти совпадают. Поисковик будет выбирать между двумя страницами, и ни одна не получит весь вес. |
| Доказательства | Title и H1 главной (рендер) и HTML посадочной — раздел 1 |
| Затронутые файлы и компоненты | Главная (production), `/kontraktnye-zapchasti-barnaul/` |
| Влияние на пользователя и бизнес | Нестабильные позиции по главному коммерческому кластеру |
| Рекомендуемое решение | Развести интенты после Wordstat. Вариант по умолчанию: главная — бренд и общий кластер («Запчасти Mercedes-Benz и BMW с японских доноров — MB Kuzbass, Барнаул»), посадочная — «контрактные запчасти». Или наоборот, но не одно и то же. Если посадочная не даёт ничего сверх главной — 301 на главную. |
| Ответственный | Senior SEO Strategist |
| Сложность | XS (после Wordstat) |
| Тестирование | Вебмастер: какая страница показывается по кластеру; уникальность Title и H1 |

### H-17. Посадочные страницы почти не связаны с сайтом

| Поле | Значение |
|---|---|
| Критичность | High |
| Область | Внутренняя перелинковка, индексация |
| Описание | Главная (SPA) не ссылается ни на одну из 7 посадочных: в JS-бандле их адресов нет. Посадочные ссылаются только на две «соседние» каждая. На `/kuzovnye-detali-optika-mercedes-bmw-barnaul/` не ведёт ни одна внутренняя ссылка — она доступна только через sitemap. |
| Доказательства | Поиск по `index-Becp_fqA.js` — 0 вхождений; ссылки посадочных — раздел 1 |
| Затронутые файлы и компоненты | Главная, все посадочные |
| Влияние на пользователя и бизнес | Слабый вес и медленное переобход посадочных; посетитель главной не попадает на них |
| Рекомендуемое решение | Ссылки на все посадочные — в шапке или блоке «Направления» главной (обычные `<a href>`), в футере всех страниц, на каждой посадочной — блок со ссылками на все остальные; позже — по схеме [12-internal-linking.md](12-internal-linking.md) |
| Ответственный | Senior Technical SEO + Senior Frontend Engineer |
| Сложность | S |
| Тестирование | Краулер: у каждой посадочной ≥ 3 входящих внутренних ссылок, глубина ≤ 2 |

### H-18. «Каталог» на посадочных открывает главную с самого верха

| Поле | Значение |
|---|---|
| Критичность | High |
| Область | CRO, навигация, баг |
| Описание | В шапке посадочных пункт «Каталог» ведёт на `/#catalog`. Приложение при первой загрузке намеренно убирает `#catalog` из адреса и прокручивает страницу наверх. Посетитель из поиска, нажавший «Каталог», видит начало главной, а не каталог. «Контакты» (`/#contacts`) работают. |
| Доказательства | Chromium: переход с `/zapchasti-mercedes-barnaul/` по «Каталог» → URL `https://mb-kuzbass.ru/`, прокрутка 0, блок каталога не виден; код: `App.jsx:840-849` |
| Затронутые файлы и компоненты | `App.jsx` (`handleHashChange`), шапка всех посадочных |
| Влияние на пользователя и бизнес | Главный путь «посадочная → ассортимент» сломан |
| Рекомендуемое решение | Быстро: при первой загрузке с `#catalog` прокручивать к каталогу (убрать сброс). Потом — реальный URL каталога после SSG |
| Ответственный | Senior Frontend Engineer |
| Сложность | XS |
| Тестирование | E2E: переход с каждой посадочной по «Каталог» → блок каталога в зоне видимости |

### M-16. Адрес без слэша перенаправляется через HTTP

| Поле | Значение |
|---|---|
| Критичность | Medium |
| Область | Техническое SEO |
| Описание | `https://mb-kuzbass.ru/zapchasti-mercedes-barnaul` → 301 на `http://…/` → 301 на `https://…/`. Два перехода и временный переход на незащищённый протокол. Причина: TLS завершается на nginx (openresty), а Apache (`mod_dir`) строит адрес со схемой `http`. |
| Доказательства | `curl -I` (раздел 2) |
| Затронутые файлы и компоненты | `.htaccess` |
| Влияние на пользователя и бизнес | Лишний переход для ссылок без слэша; для браузеров с HSTS незаметно, для роботов — цепочка |
| Рекомендуемое решение | В `.htaccess` до `mod_dir`: правило, добавляющее слэш сразу с `https://mb-kuzbass.ru` (для каталогов), или `DirectorySlash Off` + явное правило. Учесть `X-Forwarded-Proto` (как в ветке `claude/focused-gates-ld1ci1`) |
| Ответственный | Senior Backend Engineer |
| Сложность | XS |
| Тестирование | `curl -I` без слэша → один 301 сразу на `https://…/` |

### L-09. Перенос слова в H1 посадочных на мобильном

На 390 px слово «Контрактные» в H1 разрывается посередине («Контрактны / е»). Решение: уменьшить кегль H1 на узких экранах (`clamp()`), `hyphens: auto` при `lang="ru"`, без `word-break: break-all`. Скриншот: [live-mobile-landing-mercedes.jpg](evidence/production-2026-10-02/live-mobile-landing-mercedes.jpg). Senior UI/UX Designer, XS.
