# 18. Дорожная карта на 30 / 60 / 90 дней

Отсчёт — с момента утверждения плана. Сроки предполагают, что владелец отвечает на вопросы и даёт доступы в первую неделю. Задачи DEV-* — из [17-development-tasks.md](17-development-tasks.md).

## 0–30 дней: фундамент

**Фокус:** критическое техническое SEO, индексация, корректная аналитика, коммерческие факторы, Title и H1, главные посадочные страницы, локальное SEO, быстрые победы.

| Неделя | Что делаем | Задачи | Результат |
|---|---|---|---|
| 1 | Заморозка выкладок, снимок production, синхронизация с репозиторием; отключение GitHub Pages; редиректы в исходниках; проверка заголовков production; зелёный CI; удаление `aggregateRating`; обновление политики ПДн (Cloudflare, путь заявки) | DEV-01…08 | Инфраструктура не теряет правки и редиректы |
| 1 | Доступы: Вебмастер, Метрика, Яндекс Бизнес, Search Console; сбор Wordstat по [методике](03-wordstat-research.md); ответы владельца на вопросы | — | Реальные данные вместо гипотез |
| 1–2 | Путь заявки: заявки в `@MB_Kuzbass` вместо Telegram-группы, синхронное открытие, WhatsApp с текстом, телефон в шапке, липкая панель, компактный cookie-баннер, VIN-блок, коды источника | DEV-10…15 | Больше обращений с текущего трафика; лиды связаны с источником |
| 2 | Цели Метрики с параметрами, журнал лидов, базовая линия KPI | DEV-15, [14-analytics-tracking-plan.md](14-analytics-tracking-plan.md) | Измеримая воронка |
| 2 | Яндекс Бизнес, 2ГИС, единый NAP, регион сайта Барнаул | [10-local-seo-plan.md](10-local-seo-plan.md) | Сильнее локальные сигналы |
| 2–3 | Тесты (Vitest, Playwright, axe, HTML без JS), автоматическая выкладка | DEV-20…22 | Безопасная миграция |
| 3–4 | SSG: маршруты, пререндер, перенаправление хешей, sitemap, JSON-LD, error-страницы | DEV-30…34, DEV-36 | Индексируемые страницы: главная, бренды, категории, служебные |
| 4 | Title, Description, H1 по данным Wordstat; утверждение финальной структуры | [09-on-page-plan.md](09-on-page-plan.md) | Страницы под подтверждённые кластеры |

Контрольная точка 30 дней: production = репозиторий; CI зелёный; в sitemap бренды, категории, служебные страницы; цели и журнал лидов работают; Wordstat собран.

## 31–60 дней: расширение и конверсия

**Фокус:** семантическое расширение, страницы категорий и моделей, перелинковка, улучшение контента, товарное SEO, CRO.

| Что делаем | Задачи | Результат |
|---|---|---|
| Модель данных товара, страницы товаров, жизненный цикл статусов | DEV-40, DEV-41 | 30+ индексируемых карточек с реальными данными |
| Контент категорий и брендов; служебные страницы с реальными условиями | DEV-42, DEV-50 | Коммерческие факторы закрыты |
| Направления: авто из Японии, поставки для разборов | DEV-51 | Отдельные посадочные под B2B и авто |
| Перелинковка и хлебные крошки | [12-internal-linking.md](12-internal-linking.md) | Глубина ≤ 3 клика, нет сирот |
| Скорость: параллакс, `srcset`, кэш; доступность | DEV-60…62 | LCP (лаб., mobile) ≤ 2,5 с; axe без серьёзных нарушений |
| Разделение `App.jsx`, удаление мёртвого кода | DEV-35 | Проще и безопаснее изменения |
| Справочники разборок, профили площадок со ссылками | [16-backlink-authority-plan.md](16-backlink-authority-plan.md) | Корректный NAP и переходы |
| Первые итерации по данным Вебмастера: Title и сниппеты с низким CTR | — | Рост CTR |

Контрольная точка 60 дней: в индексе Яндекса и Google товарные и категорийные страницы; есть показы по небрендовым коммерческим кластерам; лиды из органики фиксируются в журнале.

## 61–90 дней: длинный хвост и рост

**Фокус:** длинный хвост, контент-стратегия, авторитет, решения на данных, оптимизация конверсии.

| Что делаем | Задачи | Результат |
|---|---|---|
| Страницы моделей и кодов агрегатов — только прошедшие правила | DEV-52 | Покрытие «модель + деталь», «код + купить» |
| Статьи с подтверждённым спросом (до 3–5) с переходом к товарам | DEV-52, [11-content-plan.md](11-content-plan.md) | Информационный трафик с путём к продаже |
| Импорт наличия из источника правды | DEV-43 | Актуальный каталог без ручной работы |
| Мониторинг, ошибки JS, web-vitals | DEV-63 | Проблемы видны до клиентов |
| Отзывы: процесс сбора и ответов | M-11 | Больше социальных доказательств |
| Ежемесячный разбор: запросы → страницы → лиды → продажи; перераспределение усилий | [14-analytics-tracking-plan.md](14-analytics-tracking-plan.md) | Решения на данных |
| A/B или последовательные тесты CTA и карточки товара (при достаточном трафике) | — | Рост конверсии органики |

Контрольная точка 90 дней: стабильный рост показов и кликов по коммерческим кластерам (Вебмастер); растущая доля лидов с кодом источника «S»; продажи из органики учитываются ежемесячно.

## Риски плана

| Риск | Что делаем |
|---|---|
| Владелец не даёт фактов (условия, цены, наличие) | Страницы с условиями не публикуются; приоритет — техника и конверсия |
| Wordstat покажет малый спрос по моделям и кодам | Меньше страниц, больше внимания картам и площадкам |
| Регрессии при миграции на SSG | Тесты до миграции, выкладка поэтапно, откат |
| Параллельная работа в разных ветках | Одна интеграционная ветка, ревью ветки `claude/focused-gates-ld1ci1` до начала |
