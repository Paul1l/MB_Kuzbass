# 12. План внутренней перелинковки (фаза 13)

Сейчас внутренних ссылок между страницами нет: есть только якоря на одной странице (C-02). Схема ниже начинает работать после перехода на реальные URL.

## Схема связей

```text
                 ┌──────────── Главная ────────────┐
                 │                                  │
        Mercedes-Benz / BMW (бренды)         Каталог (категории)
           │            │                       │
   Модели (условно)     └──── Товары ◄──────────┘
           │                   ▲  ▲
           └───────────────────┘  │
   Статьи (условно) ──────────────┘ (и на категорию, и на форму VIN)
   Доставка, гарантия, контакты ◄── со всех коммерческих страниц
```

## Правила

| Откуда | Куда | Как |
|---|---|---|
| Главная | Все категории, оба бренда, 6–12 последних товаров, доставка, контакты, направления | Карточки и навигационные блоки |
| Бренд | Модели (если есть), категории с фильтром бренда, товары бренда | Блок «Модели в наличии», списки товаров |
| Модель | Товары модели по категориям; бренд; категории | Группировка по категориям |
| Категория | Все товары категории; соседние категории; бренды | Список товаров, блок «Смотрите также» |
| Товар | Категория и бренд (крошки); 4–8 похожих (та же модель, тот же код, та же категория); доставка | Крошки, блок «Похожие позиции» |
| Товар «продано» | Похожие в наличии, категория, форма VIN | Блок «Есть в наличии» |
| Статья | 1–3 релевантных товара, категория, форма VIN | Контекстные ссылки в тексте и блок «Есть в наличии» |
| Все страницы | Шапка: каталог, бренды, доставка, контакты; футер: категории, бренды, служебные | Сквозная навигация |

## Анкоры

- Естественные и разные: «двигатели Mercedes-Benz», «смотреть все АКПП», «фары для W212», «M272 с W211 в наличии».
- Не повторять один и тот же точный коммерческий запрос во всех ссылках на страницу.
- В сквозной навигации — короткие названия разделов («Двигатели», «Оптика»).
- Ссылки на статьи из коммерческих страниц — только когда статья отвечает на вопрос покупателя («Как проверить контрактный двигатель»).

## Технические требования

1. Все ссылки — обычные `<a href="/путь/">` в HTML без JS (не `onClick` с `preventDefault` и не хеши).
2. Хлебные крошки на всех внутренних страницах + `BreadcrumbList`.
3. Глубина: любой товар — не больше 3 кликов от главной (Главная → Категория → Товар).
4. Нет страниц-сирот: каждый товар есть хотя бы в категории и в sitemap.
5. Внешние ссылки на Telegram, WhatsApp, VK, 2ГИС, Drom — как сейчас, с `rel="noopener noreferrer"`.
6. После публикации проверить отчёт «Внутренние ссылки» в Вебмастере и сканирование краулером (Screaming Frog или аналог).
