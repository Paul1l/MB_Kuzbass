# 17. Задачи для разработки

Все задачи выполняются **после утверждения плана**, небольшими изменениями, с тестами и замером «до и после». Ни один рабочий URL не удаляется без анализа редиректов. Контент и факты бизнеса не придумываются.

Перед началом проверить невлитую ветку `claude/focused-gates-ld1ci1`: в ней уже есть части DEV-03, DEV-05, DEV-08, DEV-62 — их нужно отревьюить, а не делать заново.

## Определение готовности для любой задачи

1. Изменение в исходниках `app/`, а не в собранных файлах.
2. Тесты и `npm run check` зелёные.
3. Проверка HTML без JS для затронутых страниц.
4. Замер «до и после» (Lighthouse или цели), если задача влияет на скорость или конверсию.
5. Запись в журнал изменений с датой выкладки (для анализа эффекта в Вебмастере и Метрике).
