# Безопасность сайта MB Kuzbass

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в открытом issue. Отправьте краткое описание, адрес страницы, шаги воспроизведения и возможное влияние через Telegram: https://t.me/mbc_kuzbass.

Не прикладывайте реальные персональные данные клиентов, пароли, cookie, токены доступа или платежные реквизиты. Для примера используйте вымышленные данные.

## Поддерживаемая версия

Исправления безопасности применяются к текущей версии ветки `main` и опубликованному сайту https://mb-kuzbass.ru/.

## Ожидаемый порядок

1. Получение и первичная проверка сообщения.
2. Ограничение доступа при подтвержденном риске.
3. Подготовка исправления и проверка production-сборки.
4. Публикация исправления без раскрытия данных пользователей.
5. При затрагивании персональных данных — выполнение порядка уведомления и расследования из `docs/personal-data/INCIDENT-RESPONSE.md`.
