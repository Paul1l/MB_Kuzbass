# Обновление каталога

Каталог сайта хранится отдельно от React-компонентов:

- `catalog-products.json` — категории, названия, описания и соответствие исходных/готовых фото.
- `public/assets/catalog/` — обработанные изображения, которые попадают на сайт.
- `src/catalog.js` — преобразует JSON в данные для интерфейса.

## Как добавить товар

1. Положите исходное фото в папку с понятным названием категории и товара.
2. Добавьте товар в нужную категорию файла `catalog-products.json`.
3. В `sourceImages` укажите путь от корня папки с исходными фото.
4. В `images` задайте латинское имя итогового файла с расширением `.webp`.
5. Запустите импорт:

```powershell
npm run import:catalog -- "C:\путь\к\Каталог товаров"
```

6. Проверьте и соберите сайт:

```powershell
npm run check
```

Для нескольких ракурсов добавьте одинаковое количество путей в `sourceImages` и `images`. Сайт автоматически покажет ручное переключение фотографий.

Сценарий импорта не меняет оригиналы. Он поворачивает изображение по EXIF, приводит его к формату 800×600, выполняет умеренную коррекцию, удаляет метаданные и добавляет знак `MB KUZBASS / ФОТО ТОВАРА`.

Обработка и маркировка не заменяют разрешение правообладателя. Для фото с внешних площадок необходимо сохранять подтверждение разрешения на публикацию.

## Если удаляете товар

Карточка сама пропадёт со страниц каталога и из блока «Примеры со склада» на посадочных (его собирает `scripts/generate-catalog-pages.mjs`, объект `landingExamples`). Но тексты посадочных называют детали каталога по названию: модели, кузова, моторы — список `landingCatalogMentions` в `scripts/verify-build.mjs`. Если удалённая деталь там есть, `npm run check` остановится с подсказкой: поправьте текст посадочной, включая «Частые вопросы» и разметку FAQPage в её JSON-LD (вопросы и ответы в разметке должны совпадать с видимыми слово в слово), и сам список.
