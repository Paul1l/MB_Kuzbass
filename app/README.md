# MB Kuzbass site

Одностраничное React-приложение для MB Kuzbass: оригинальные запчасти Mercedes-Benz и BMW с японских доноров, автомобили из Японии, машинокомплекты, заявка через Telegram, footer-документы и онлайн-статистика рейтинга 2ГИС.

Текущий режим — информационная витрина. Сайт не принимает заказы и платежи, не создает аккаунты и не хранит заявки на сервере. Клиент уточняет наличие и согласовывает покупку через Telegram, WhatsApp, VK или по телефону. Режим зафиксирован в `src/data.js`, объект `commerce`.

## Запуск

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Что заливать на хостинг

Для обычного статического хостинга достаточно загрузить содержимое папки `dist`.

Внутри production-сборки есть:

- `index.html`: главная SPA-страница.
- `assets`: CSS, JS и фотографии.
- `reviews-config.js`: настройки онлайн-рейтинга 2ГИС.
- `robots.txt` и `sitemap.xml`: базовые SEO-файлы.
- `404.html`, `500.html`, `503.html`, `offline.html`: страницы ошибок.
- `.htaccess`: ошибки, кеширование и защитные HTTP-заголовки для Apache-хостинга.
- `_headers`: CSP и остальные защитные заголовки для Netlify-подобных хостингов.
- `site.webmanifest`, `favicon.svg`, `favicon.ico`, `favicon-*.png`, `sw.js`: manifest, поисковые иконки и офлайн-страница после первого посещения сайта.

## Онлайн-рейтинг 2ГИС

Сайт умеет подтягивать актуальный рейтинг и количество оценок из 2ГИС через Places API.

Настройки лежат в `public/reviews-config.js`:

```js
window.MBKUZBASS_REVIEWS_CONFIG = {
  branchId: '70000001084067232',
  endpoint: 'https://catalog.api.2gis.com/3.0/items/byid',
  fields: 'items.reviews',
  locale: 'ru_RU',
  apiKey: '',
  proxyUrl: '',
};
```

Чтобы включить прямой онлайн-запрос, нужен браузерный ключ Places API, ограниченный доменом сайта в кабинете 2ГИС. Любое значение в `reviews-config.js` публично: секретный или серверный ключ сюда вставлять нельзя.

Если ключ нельзя показывать в браузере, оставьте `apiKey` пустым и укажите `proxyUrl`: собственный backend-адрес, который вернет либо ответ 2ГИС, либо JSON вида:

```json
{
  "rating": "4.8",
  "ratingCount": 17,
  "reviewCount": 17
}
```

Официальный Places API 2ГИС отдает статистику по отзывам: средний рейтинг и количество. Тексты отзывов через этот API не выдаются, поэтому карточки отзывов на сайте остаются как вручную выбранные выдержки со ссылкой на 2ГИС/Фламп/Drom. Drom добавлен как отдельный публичный источник в `src/data.js`, поле `contact.drom` и массив `reviews`.

## Безопасность

- В проекте нет базы данных, личных кабинетов, онлайн-оплаты и серверного обработчика формы. Поля заявки обрабатываются только в браузере и копируются в буфер обмена.
- `Content-Security-Policy` в `index.html` ограничивает скрипты, изображения, подключения, фреймы и плагины разрешенными источниками.
- `.htaccess` и `_headers` дополнительно запрещают встраивание сайта во фрейм, MIME-sniffing и доступ к камере, микрофону, геолокации и платежным API.
- Все внешние ссылки с новой вкладкой используют `noopener noreferrer`.
- Cookie настроек не содержит персональных данных, устанавливается с `SameSite=Lax`, а на HTTPS дополнительно получает атрибут `Secure`.
- Яндекс.Метрика загружается только после отдельного согласия на аналитику; содержимое формы скрыто от Вебвизора.
- Service worker обслуживает только GET-навигацию внутри текущего домена и не кеширует ответы внешних сайтов.
- Dev- и preview-серверы привязаны к `127.0.0.1`, поэтому исходники не публикуются в локальную сеть случайно.
- Перед каждой публикацией запускайте `npm audit` и `npm run build`. Не добавляйте токены, пароли, банковские ключи или секреты в `src`, `public`, `.env` с префиксом `VITE_` либо собранные файлы.

Production-файлы и DNS-зона домена размещаются на Спринтхосте (домен зарегистрирован в Webnames, Cloudflare не используется). Заголовки безопасности, редиректы на `https://mb-kuzbass.ru` и адреса со слэшем настраиваются в `public/.htaccess`, он же закрывает служебные папки (`app`, `audit`, `docs`, `.git`) и `.md`-файлы, если на хостинг случайно загрузили весь репозиторий. GitHub используется только как репозиторий исходников и истории изменений.

## Error-страницы

В `public` подготовлены отдельные страницы:

- `404.html`: если пользователь открыл несуществующий адрес.
- `500.html`: если хостинг поддерживает свою страницу внутренней ошибки.
- `503.html`: если сайт временно на обслуживании.
- `offline.html`: если пользователь уже открывал сайт раньше, а потом потерял соединение.

Если сервер или хостинг полностью недоступен и пользователь ни разу не открывал сайт, браузер не сможет получить даже error-страницу. Это ограничение любого сайта: страницу ошибки должен отдать сам сервер или уже установленный service worker.

## Дизайн главной

Главная собрана по макету «Новый дизайн MB Kuzbass» (октябрь 2026): заголовок «Mercedes-Benz и BMW из Японии — по запчастям и целиком», на первом экране две формы — «Нужна запчасть» и «Хочу авто из Японии». На телефоне вместо двух форм — переключатель, фото первого экрана не загружаются, внизу экрана панель «Позвонить / Telegram / WhatsApp».

- Палитра: графит `#121417`, светлый фон `#f4f2ec` и жёлтый акцент `#ffc72c`, как бирки MB KUZBASS на фото деталей. Переменные — в начале `src/styles.scss`.
- Шрифты Onest (400, 600, 700, 800) и JetBrains Mono (700, для кодов кузовов и агрегатов) лежат в `src/fonts` вместе с лицензиями OFL. Подключаются со своего домена: CSP сайта не разрешает Google Fonts. Плагин в `vite.config.js` добавляет предзагрузку Onest 400 и 800, иначе заголовок перерисовывается и сдвигает формы.
- Посадочные страницы используют тот же акцент в `public/seo-pages.css`.
- На телефоне «Примеры с нашего склада» и «Уже заказали в Японии» листаются вбок, поэтому фото внутри карточки машины переключаются кнопками, а не свайпом.

- В `index.html` добавлены title, description, canonical, Open Graph, Twitter Card, geo-meta, favicon, manifest и JSON-LD `AutoPartsStore`.
- В `sitemap.xml` указаны главная и 7 посадочных страниц.

```

  App.jsx             состояние страницы, эффекты и обработчики; собирает главную из блоков
  data.js             весь контент: контакты, тексты, машины из Японии, юридические документы
  catalog.js          каталог из catalog-products.json
  sections/           блоки главной в порядке на странице
    HeroSection.jsx       первый экран: заголовок, формы «Нужна запчасть» и «Хочу авто из Японии», факты
    DonorsSection.jsx     «Частые доноры»
    CatalogSection.jsx    «Каталог запчастей»
    FeaturedSection.jsx   «Примеры с нашего склада»
    StepsSection.jsx      «Как купить деталь»
    DirectionsSection.jsx «Авто из Японии и поставки для разборов»
    JapanCarsSection.jsx  «Уже заказали в Японии»
    TrustSection.jsx      «Почему нам доверяют» и отзывы
    ContactsSection.jsx   контакты
  components/         общие части интерфейса
  lib/                функции без интерфейса: текст заявки и копирование, навигация по якорям, картинки
  analytics.js, privacyConsent.js, onlineReviews.js, assetUrl.js
```

Блоки главной получают из `App` только то, что меняется (выбранная форма, статус заявки, рейтинг 2ГИС, обработчики); постоянный контент каждый блок берёт из `data.js` сам.

Компоненты (`src/components`):

- `Icon`: рисует контурную иконку из набора `iconPaths`.
- `Header`: верхняя строка с адресом, шапка с меню, телефоном и Telegram; на планшете и телефоне меню открывается кнопкой.
- `MobileContactBar`: нижняя панель «Позвонить / Telegram / WhatsApp» на экранах до 820 px.
- `FormStatus`: сообщение под формой после нажатия и запасная ссылка на чат.
- `ConsentCheckbox`: отдельное согласие на обработку ПДн со ссылкой на документ.
- `CatalogProductGallery`, `CatalogCategoryPage`: внутренняя SPA-страница выбранной категории каталога.
- `JapanCarCard`: карточка «Уже заказали в Японии» — фото листаются стрелками под снимком (не закрывают машину), кнопка «Хочу похожий» открывает `@MB_Kuzbass` с моделью в сообщении.
- `LegalLink`: открывает footer-документ в модальном окне.
- `LegalModal`: показывает выбранный юридический документ поверх страницы.
- `CookieBanner`: выбор необходимых cookie и отдельного согласия на аналитику.
- `Footer`: бренд и реквизиты, ссылки на посадочные страницы и документы.

Функции (`src/lib` и `src/privacyConsent.js`):

- `createRequestText`: собирает текст заявки из полей формы запчасти или автомобиля, с отметкой о согласии.
- `copyRequestText`: копирует заявку в буфер в момент нажатия (синхронно через выделение поля, запасной вариант — Clipboard API), до открытия Telegram.
- `getCatalogSlugFromHash`: достает slug категории из адреса вида `#catalog/engines`.
- `schedulePageAnchorScroll`, `schedulePageTopReset`: прокрутка к разделу из адреса и сброс прокрутки на первом экране; повторяются несколько раз, потому что картинки догружаются и сдвигают страницу.
- `handleImageError`, `EMPTY_IMAGE`: заглушка вместо не загрузившейся картинки и пустая картинка вместо фото первого экрана на телефоне.
- `readPrivacyPreferences`, `savePrivacyPreferences`: читают и сохраняют выбор cookie (на 180 дней).

Обработчики внутри `App`:

- `handleLeadSubmit`: формирует заявку, копирует текст и в том же нажатии открывает личный чат `@MB_Kuzbass` (без `await` перед `window.open`, иначе Safari на iPhone может заблокировать вкладку).
- `handleDonorPick`: подставляет модель из «Частых доноров» в форму запчасти и переводит к полю детали.
- `handleCatalogOpen`: открывает выбранную категорию каталога и сбрасывает прокрутку наверх.
- `handleEscape`: закрывает документ и меню по клавише Escape.
- `handleHashChange`: синхронизирует hash URL с состоянием SPA-каталога.
- `syncReviews`: загружает актуальный рейтинг 2ГИС, если настроен ключ или proxy.

## Проверки и тесты

```bash
npm run check   # линтер, сборка со структурной проверкой, npm audit
npm test        # браузерные тесты по собранному сайту: сначала npm run build
```

- `scripts/verify-build.mjs` запускается в конце `npm run build` и останавливает сборку, если сломано важное: заявки ведут не в `@MB_Kuzbass`, главная или посадочная не ссылается на все посадочные из `sitemap.xml`, пропал файл каталога или фото машины, вернулся `aggregateRating`, исчезли обязательные юридические тексты.
- `tests/` — тесты Playwright в Chromium, на компьютере (1440×900) и телефоне (размеры iPhone 13): обе формы заявки, «Частые доноры», каталог, документы, меню и панель связи на телефоне, плашка cookie, «Уже заказали в Японии» и все 7 посадочных. Каждый тест падает и при ошибке в консоли браузера. Файлы `*.desktop.spec.js` идут только на компьютере, `*.mobile.spec.js` — только на телефоне.
- GitHub Actions (`.github/workflows/site-ci.yml`) на каждом PR и при изменении main запускает `npm run check` и `npm test`, а готовую сборку сохраняет как артефакт `mb-kuzbass-dist`.

## Что делает `src/onlineReviews.js`

- `getRuntimeConfig`: читает runtime-настройки из `window.MBKUZBASS_REVIEWS_CONFIG`.
- `cleanValue`: безопасно приводит значение к строке.
- `isReadyApiKey`: проверяет, что API-ключ не пустой и не шаблонный.
- `readNumber`: преобразует рейтинг в число.
- `readInteger`: преобразует количество оценок и отзывов в целое число.
- `pluralizeRu`: подбирает русскую форму слова для чисел.
- `buildDirectApiUrl`: собирает прямой URL запроса к API 2ГИС.
- `buildReviewsUrl`: выбирает proxy-url или прямой URL API.
- `getConfig`: объединяет дефолтные настройки, `data.js` и runtime-конфиг.
- `getReviewsBlock`: достает блок отзывов из разных форматов JSON-ответа.
- `createMetaFromStats`: нормализует рейтинг и количество оценок в формат сайта.
- `isOnlineReviewsConfigured`: проверяет, можно ли включать онлайн-загрузку.
- `loadOnlineReviewsMeta`: загружает данные, возвращает актуальную статистику или резервные значения.

## Юридические ссылки

Юридические тексты не выводятся длинным блоком на странице. Они открываются по ссылкам в footer:

- Политика конфиденциальности.
- Согласие на обработку ПДн.
- Пользовательское соглашение.
- Cookie.
- Условия заказа, оплаты, доставки и возврата.

Счетчик Яндекс.Метрики `111089917` подключен через `public/analytics-config.js`. Он загружается только после отдельного согласия на аналитику, учитывает SPA-переходы вручную и использует Вебвизор с полным скрытием формы заявки. При смене счетчика или режима Вебвизора нужно обновить конфигурацию, версию согласия в `src/privacyConsent.js` и юридические тексты в `src/data.js`.

Статический код `<noscript>` намеренно не добавлен: он отправлял бы запрос в Метрику до выбора пользователя. При подключении рекламных пикселей, CRM, backend-форм или сторонних виджетов нужно заранее обновить документ `cookies`, политику обработки данных и интерфейс согласия.

В каталоге `../docs/personal-data` подготовлены черновик уведомления Роскомнадзора, анкета владельца, внутренний регламент, отдельное согласие на распространение, акт удаления и план реагирования на инциденты. Это рабочие шаблоны: подачу нельзя считать завершенной, пока владелец не подтвердил закрытые сведения, не учел все процессы ИП за пределами сайта и не подписал официальное уведомление.

Форма заявки не отправляет сведения на backend. `handleRequestSubmit` собирает и копирует текст локально, после чего пользователь самостоятельно отправляет его в Telegram. При подключении backend-формы нужно до запуска настроить защищенную передачу, хранение, удаление данных, уведомление оператора ПДн и обновить политику с согласием.

## Подготовка к интернет-магазину

Перед включением корзины, регистрации или онлайн-оплаты нужно:

- добавить серверную модель товаров, остатков и заказов;
- опубликовать актуальную оферту, способы оплаты, доставки и возврата;
- подключить платежного оператора и онлайн-кассу, если они требуются выбранной схеме расчетов;
- обновить политику ПДн, согласие, cookie и сведения о сроках хранения;
- обеспечить подтверждение заказа, передачу обязательной информации о товаре и порядок направления претензий;
- повторно проверить SEO, безопасность, доступность и мобильную верстку.

## Перед публикацией

- Основной адрес сайта: `https://mb-kuzbass.ru/`. При смене домена обновить `src/data.js`, canonical, Open Graph, JSON-LD, `robots.txt` и `sitemap.xml`.
- Получить ключ Places API 2ГИС или настроить proxy-url для онлайн-рейтинга.
- Сверить юридическое название владельца, ИНН/ОГРН/ОГРНИП и добавить их в `src/data.js`, если клиент передаст реквизиты.
- Проверить, что отзывы и фото разрешено использовать на сайте.
- Не редактировать файлы в `dist` вручную: правки вносить в `src`, затем заново запускать `npm run build`.
