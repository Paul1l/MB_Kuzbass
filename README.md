# МБ Кузбасс / MB Kuzbass

Информационная витрина запчастей Mercedes-Benz и BMW с японских доноров, автомобилей с японских аукционов и поставок для авторазборов.

Сайт не принимает заказы и платежи, не создает аккаунты и не хранит заявки на сервере. Клиент уточняет наличие и согласовывает покупку через Telegram, WhatsApp, VK или по телефону.

## Структура репозитория

- Корень репозитория: готовая статическая сборка для загрузки на Спринтхост. GitHub используется для хранения исходников и истории изменений, а не как владелец или текущий хостинг сайта.
- `app`: поддерживаемый исходный проект React + Vite + SCSS.
- `app/src/data.js`: контакты, каталог, фотографии, отзывы, юридические документы и режим работы сайта.
- `app/src/App.jsx`: состояние и поведение SPA; блоки главной — в `app/src/sections`, общие компоненты — в `app/src/components`, вспомогательные функции — в `app/src/lib` (подробно — в `app/README.md`, раздел «Устройство кода»).
- `app/tests`: браузерные тесты (`npm test`), запускаются в GitHub Actions на каждом PR.
- `app/src/styles`: стили по блокам страницы, цвета и размеры — в `_tokens.scss`, адаптивная верстка — в `_responsive.scss`.
- `app/public/assets`: фотографии и остальные статические материалы.
- `docs/personal-data`: черновик уведомления Роскомнадзора, анкета владельца и внутренние шаблоны по персональным данным.
- `LEGAL-LAUNCH-CHECKLIST.md`: текущее состояние юридической и технической подготовки.
- `SECURITY.md`: правила сообщения об уязвимостях и обращения с секретами.

## Локальный запуск

```bash
cd app
npm install
npm run dev
```

## Production-сборка

```bash
cd app
npm run build
```

После сборки содержимое `app/dist` нужно скопировать в корень репозитория и проверить локально. Не редактируйте скомпилированные файлы `assets/index-*.js` и `assets/index-*.css` вручную.

Подробное описание функций, SEO, отзывов 2ГИС, error-страниц и подготовки к интернет-магазину находится в `app/README.md`. Заполненную анкету владельца с адресом, email и сведениями о базах данных нельзя хранить в публичном репозитории.
